# abed-page: personal portfolio

Source for my portfolio site at **[abed-page.vercel.app](https://abed-page.vercel.app)**. It covers my work as a Flutter + .NET engineer shipping AI features in production mobile apps, plus my projects, publications and CV.

## Features
- Home page with bio, experience, skills and contact links
- Works page, with a detail page for each project
- 3D voxel model on the hero, rendered with Three.js
- Light and dark theme toggle
- Downloadable CV (PDF) generated from the same content as the site (`scripts/generate_cv.py`)
- Deployed on Vercel. Every push to the main branch redeploys the site

## Tech stack
- **Next.js**, **React**
- **Chakra UI**, **Emotion**, **Framer Motion**
- **Three.js**
- **Vercel**

## Run it
```bash
npm install
npm run dev
```
Open http://localhost:3000.
